# 🎵 Windows Media Player Widget (v0.2)

Un reproductor flotante minimalista para Windows construido en Python que muestra la canción en reproducción y la portada del álbum usando controles del sistema.

## 🚀 Características (v1.0)
- **Interfaz personalizada:** Diseño sin marcos con ventana flotante siempre visible.
- **Lectura de metadatos:** Muestra portada del álbum, título, artista y barra de progreso sincronizada en tiempo real.
- **Controles de medios:** Botones integrados de reproducción, pausa, pista anterior y pista siguiente.
- **Ventana desplazable:** Arrastra la ventana libremente por la pantalla.

## 📥 Descarga rápida
Puedes descargar el ejecutable listo para usar sin necesidad de instalar Python en la sección de [Releases](../../releases/tag/v1.0.0).

## 🛠️ Tecnologías utilizadas
- Python 3
- CustomTkinter
- Pillow (PIL)
- WinRT (Windows Media Transport Controls)
